# 🚖 Uber Data Analysis Dashboard – 2024

## 📌 Project Overview

This project presents an interactive **Uber Data Analysis Dashboard** built using **Microsoft Power BI**. The dashboard analyzes Uber ride-booking data to understand booking performance, revenue, vehicle types, payment methods, ride status, and customer/driver-related metrics.

The objective is to transform raw ride-booking data into meaningful visual insights that can support data-driven decision-making.

## 🎯 Objectives

* Analyze overall Uber booking performance
* Understand revenue generated from different ride categories
* Compare vehicle types based on bookings and revenue
* Analyze completed and cancelled rides
* Identify popular payment methods
* Understand ride-distance and booking trends
* Create an interactive dashboard for business analysis

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development and data visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and calculations
* **Excel / CSV** – Data preparation and analysis

## 📊 Dashboard Highlights

The dashboard provides analysis of:

* Total bookings
* Total revenue
* Completed rides
* Cancelled rides
* Average driver rating
* Vehicle type performance
* Payment method distribution
* Booking status
* Ride distance
* Revenue trends

## 📈 Key Insights

Based on the analyzed dataset:

* Total revenue is approximately **₹51.85M**
* Average driver rating is approximately **4.23**
* Completed rides contribute approximately **₹47.26M** in revenue
* **UPI** represents approximately **45%** of payment methods
* **Premier Sedan** and **Go Sedan** are among the higher-revenue vehicle categories

> Note: These figures are based on the dataset included in this project and are intended for analytical demonstration.
